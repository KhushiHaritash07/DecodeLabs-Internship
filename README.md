# Project 2: Text Encryption & Decryption Tool 🔐

## Overview
This is a C++ console application designed to encrypt and decrypt text. It allows users to input a message and securely transform it, as well as revert an encrypted message back to its original readable format. 

## Features
* **Encryption:** Converts standard text into an encrypted format using a specific algorithm.
* **Decryption:** Reverses the encryption process to reveal the original hidden message.
* **Simple UI:** Easy-to-use command-line interface for quick inputs and outputs.

## Technologies Used
* **Language:** C++
* **IDE/Environment:** Visual Studio Code (MacOS)
